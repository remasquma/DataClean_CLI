#  DataClean CLI

A lightweight, privacy-first command-line tool built with Python to clean, profile, and convert your data files effortlessly.
---

##  Features

- **Smart Encoding Detection:** Automatically handles non-ASCII and Arabic text via `utf-8-sig` fallback.
- **Quick Data Profiling:** Prints a clean, colorful summary table (rows, columns, memory usage, missing values) using Rich.
- **Effortless Cleaning:** Remove duplicate rows, strip whitespace, drop empty rows/columns, and standardize dates with simple flags.
- **Recipe Support:** Save your favorite cleaning steps in a JSON or YAML file and re-apply them instantly.
- **Multi-Format Conversion:** Easily convert between CSV, JSON, and Excel (`.xlsx`, `.xls`).

---
Install the required dependencies:
